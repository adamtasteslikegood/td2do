# td2do phase 1 (`list`, offline `check`, `init`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Rust binary, `td2do`, that lists every TODO comment in a repo and fails a branch that adds a TODO without an issue reference, with no network.

**Architecture:** A pipeline of small modules: walker → prefilter → comment lexer → TODO parser → (diff filter) → rules / output. Git is
reached by running the `git` binary; nothing is stored between runs. The issue backend (phase 2) is not part of this plan.

**Tech Stack:** Rust (edition 2024), `clap` (derive), `ignore`, `grep-searcher` + `grep-regex` + `grep-matcher`, `regex`, `sha2`, `serde` +
`serde_json`, `toml`, `anyhow`, `globset`. Tests: `assert_cmd`, `predicates`, `tempfile`, `proptest`.

**Spec:** [`docs/specs/2026-10-29-td2do-design.md`](../specs/2026-10-29-td2do-design.md), sections 3, 4, 6, 7, 8, 11, 12, 13.

## Global Constraints

- Binary `td2do`; config `.td2do.toml` at the repo root, every key optional; inline escape `td2do:ignore`.
- Default tags `["TODO", "FIXME", "HACK", "XXX", "BUG"]`, uppercase, matched on a word boundary, only inside comments.
- REF forms: `gh#123`, `gh:owner/repo#123`; `#123` reads as `gh#123` only when `origin` is on GitHub; `relay:` and `jira:` are reserved
  prefixes (recognised, reported as unknown backend by `check` in phase 1).
- Fingerprint: `sha256(slug + tag + normalized text)`, first 16 hex characters; normalizing strips comment markers and REF, lowercases,
  collapses whitespace. With no `origin`, the slug is the empty string.
- Every command takes `--json`; JSON carries `"schema": 1`.
- Exit codes: 0 success, 1 check failed, 2 usage or config error. (3 is phase 2's.)
- Terminal output grouped by file with colour; piped output `path:line:col: TAG(REF) text`; `NO_COLOR` honoured.
- Skip binaries (NUL in the first 8 KB), files over 2 MB, lockfiles, minified files (`*.min.*`), and `vendor/`, `node_modules/`, `third_party/`.
- Files: `git ls-files` (plus untracked, not-ignored files) inside a repo; else `ignore::WalkParallel`.
- Output is sorted by (path, line, col) so it never depends on thread count.
- Hand style: `cargo fmt` defaults; `cargo clippy -- -D warnings` clean. Actions pinned to commit SHAs with the tag in a comment.
- Every commit message ends with `Co-Authored-By: <model> <noreply@anthropic.com>`.

**Decisions this plan makes where the spec is silent** (flag in review if wrong):

- A file whose extension has no entry in the language table is skipped, never guessed at; `--verbose` prints how many were skipped.
- Python docstrings are strings, not comments, so a TODO in a docstring is not found (spec section 8 defers this to tree-sitter).
- `check` compares the merge base with the **working tree** by default; `--staged` compares it with the index, for the pre-commit hook.
- The default base is `origin/HEAD`'s target (e.g. `origin/main`), falling back to `main`; `check.base` and `--base` override it.
- `init` in phase 1 writes the config, the hook and the CI step, **not** the agent rule: the rule names `find` and `add`, which arrive in
  phase 2. Task 7 leaves a stub that prints "agent rule: available in phase 2".

## Review Focus

1. **A file with CRLF line endings** reports the same line and column numbers as its LF twin, and TODO text carries no `\r`. (Task 3)
2. **A file that is not valid UTF-8** (Latin-1 source) is scanned lossily and never panics or aborts the run; other files still report.
   (Task 4)
3. **A base that isn't available locally** (shallow clone, base branch never fetched) makes `check` exit 2 with a message naming
   `fetch-depth: 0`, not exit 0 with nothing checked. (Task 6)
4. **A renamed file with one new TODO** counts only that line as new, not every TODO in the file. (Task 6)
5. **A path with spaces or non-ASCII characters** round-trips through `git diff` (quoted paths) and appears unquoted in output. (Task 6)

### Task 3: TODO parsing, REFs and fingerprint

**Files:**
- Create: `src/todo.rs`
- Test: `src/todo.rs` (unit)

**Interfaces:**
- Consumes: `lexer::Comment`, `lexer::CommentLine` (Task 2).
- Produces:
  - `pub enum Ref { Gh { repo: Option<String>, number: u64 }, Unknown { prefix: String, raw: String }, Malformed(String) }`
  - `pub struct Todo { pub path: PathBuf, pub line: usize, pub col: usize, pub tag: String, pub reference: Option<Ref>, pub extra: Option<String>, pub text: String, pub fingerprint: String }`
  - `pub fn parse_comment(c: &Comment, tags: &[String], github_origin: bool) -> Vec<(usize /*line*/, usize /*col*/, String /*tag*/, Option<Ref>, Option<String>, String /*text*/)>`
  - `pub fn fingerprint(slug: &str, tag: &str, text: &str) -> String`
  - `pub fn normalize(text: &str) -> String`

Parsing rules:
- A tag is one of `tags`, at the start of a comment line's text (after whitespace), followed by `(`, `:`, whitespace or end of line.
- `TAG(inner): text` — `inner` split at the first comma: the first part is the REF candidate, the rest is `extra`. A first part that is
  not REF-shaped (`alice`) makes the TODO untracked, and the whole `inner` becomes `extra`.
- REF-shaped: starts with `gh#`, `gh:`, `#`, or `<word>:` where `<word>` is lowercase letters. `gh#123` → `Gh{None,123}`;
  `gh:o/r#5` → `Gh{Some("o/r"),5}`; `#123` → `Gh{None,123}` if `github_origin`, else `Unknown{prefix:"#"}`; `relay:x`, `jira:K-1` →
  `Unknown`; `gh#abc`, `gh:o#5` → `Malformed`.
- Continuation: following lines of the same `Comment` with no tag of their own are appended to `text` with one space, until an empty line
  or another tag.
- A line containing `td2do:ignore` yields nothing.

- [ ] **Step 1: Write failing tests** — `parses_gh_ref` (`TODO(gh#12): retry` → tag `TODO`, `Gh{None,12}`, text `retry`);
  `parses_cross_repo`; `hash_ref_depends_on_origin`; `owner_is_not_ref` (`TODO(alice): x` → `None`, extra `alice`);
  `extra_after_comma` (`FIXME(gh#3, p1): y` → extra `p1`); `malformed_ref`; `relay_is_unknown`;
  `continuation_joins` (two lines → `"first second"`); `stops_at_next_tag`; `ignore_escape`; `lowercase_todo_is_not_a_tag`;
  `todolist_is_not_a_tag` (`todoList` / `TODOS` → nothing); `crlf_same_as_lf` (Review Focus 1: a `\r\n` comment gives the same
  line, col and text without `\r`);
  `fingerprint_stable` (`fingerprint("o/r","TODO","Retry  on 429")` == `fingerprint("o/r","TODO","retry on 429")`, 16 hex chars);
  `fingerprint_ignores_ref` (same text with and without `gh#1` → same fingerprint).
- [ ] **Step 2: Run** `cargo test todo` — Expected: FAIL.
- [ ] **Step 3: Implement** with one `regex` per tag set built once (`^\s*(TAG1|TAG2…)\b(?:\(([^)]*)\))?:?\s*(.*)$`).
- [ ] **Step 4: Run** `cargo test todo` — Expected: PASS.
- [ ] **Step 5: Commit** — `git add -A && git commit -m "feat: TODO parsing, references and fingerprint"`

### Task 6: Diff mode and `td2do check` (offline rules)

**Files:**
- Create: `src/check.rs`
- Modify: `src/git.rs` (diff functions), `src/main.rs` (wire `check`)
- Test: `tests/cli_check.rs`, `src/git.rs` (unit for hunk parsing)

**Interfaces:**
- Consumes: `scan::{Repo, scan, scan_source}`, `output::{ref_string, todo_json}`, `tests/support::Fixture`.
- Produces:
  - `git::default_base(root) -> String` (`git symbolic-ref --short refs/remotes/origin/HEAD`, else `"main"`)
  - `git::merge_base(root, base: &str) -> Result<String, BaseError>`; `BaseError::Missing { base }` when the ref doesn't resolve or there
    is no common ancestor (shallow clone).
  - `git::added_lines(root, merge_base: &str, staged: bool) -> anyhow::Result<HashMap<PathBuf, BTreeSet<usize>>>` — runs
    `git diff -U0 -M -z --no-color [--cached] <merge_base>` and parses `@@ -a,b +c,d @@` hunks; paths from `-z` output, so quoting never
    applies.
  - `git::index_content(root, path) -> anyhow::Result<Vec<u8>>` (`git show :<path>`)
  - `pub enum Rule { NoRef, BadRef, DuplicateText }`, `pub enum Severity { Fail, Warn }`
  - `pub struct Violation { pub rule: Rule, pub severity: Severity, pub todo: Todo, pub other: Option<Todo> }`
  - `pub fn run(todos: &[Todo], new: &dyn Fn(&Todo) -> bool, cfg: &CheckConfig) -> Vec<Violation>`
  - CLI: `td2do check [--base <ref>] [--staged] [--all] [--json]`. Exit 1 if any `Fail`; warnings print but exit 0. JSON:
    `{ "schema": 1, "passed": bool, "checked": "new"|"all", "base": "<ref>", "violations": [{ rule, severity, todo, other }] }`.

Rules (offline only):
- `NoRef` (fail): a new TODO with `reference == None`.
- `BadRef` (fail): a new TODO with `Ref::Unknown` or `Ref::Malformed`; the message names the prefix.
- `DuplicateText` (`check.duplicate_text`, default warn): a new TODO whose fingerprint equals another TODO's at a different location;
  `other` is that TODO.

- [ ] **Step 1: Write failing tests** (fixtures: `main` with an old untracked TODO, then a branch):
  - `old_todos_pass` — branch adds nothing; exit 0.
  - `new_untracked_fails` — branch adds `// TODO: x`; exit 1; stderr names the file and line; the old TODO is not listed.
  - `new_tracked_passes` — adds `// TODO(gh#4): x`; exit 0.
  - `new_relay_ref_fails_bad_ref`, `new_malformed_fails`.
  - `duplicate_warns` — adds the old TODO's exact text with a REF elsewhere; exit 0, stdout has a `DuplicateText` warning naming both.
  - `duplicate_fail_config` — with `duplicate_text = "fail"`, exit 1.
  - `staged_mode` — a staged untracked TODO fails `--staged`; an unstaged one doesn't fail `--staged` but fails the default mode.
  - `all_flag` — `--all` fails on the old untracked TODO.
  - `ignore_escape_passes` — `// TODO: x td2do:ignore` added; exit 0.
  - `missing_base_exits_2` (Review Focus 3) — `--base nope`; exit 2; stderr contains `fetch-depth: 0`.
  - `shallow_clone_exits_2` (Review Focus 3) — `git clone --depth 1 file://…` of the branch, `check --base origin/main`; exit 2.
  - `rename_counts_only_new_line` (Review Focus 4) — `git mv a.rs b.rs` plus one added TODO line; only that line is reported.
  - `odd_paths` (Review Focus 5) — a new TODO in `dir with space/é.rs`; reported path is `dir with space/é.rs`.
  - `check_json` — `schema == 1`, `passed == false`, one violation with `rule == "no_ref"`.
  - `git::tests::parses_hunks` — `@@ -3,0 +4,2 @@` → lines {4,5}; `@@ -1 +1 @@` → {1}; `+c,0` adds nothing.

- [ ] **Step 3: Implement** `git.rs` diff functions, `check.rs`, and the `check` command. A TODO is new when any of its lines (first line
